<h3>Linux Infrastructure Lab</h3>

<p>
Designed, deployed, and automated a Linux web server on AWS using Terraform and Infrastructure as Code (IaC) principles. The project focused on cloud infrastructure provisioning, Linux administration, security, automation, and testing infrastructure resilience through full rebuild validation.
</p>

<p><strong>Key Technologies:</strong></p>

<ul>
    <li>AWS EC2</li>
    <li>Amazon Linux 2023</li>
    <li>Terraform (Infrastructure as Code)</li>
    <li>AWS Security Groups</li>
    <li>SSH Key Authentication</li>
    <li>Elastic IP</li>
    <li>Nginx</li>
    <li>Cloud-Init User Data</li>
</ul>

<p><strong>Key Achievements:</strong></p>

<ul>
    <li>Provisioned AWS infrastructure using Terraform</li>
    <li>Secured administrative access using SSH key authentication and IP-based restrictions</li>
    <li>Configured Nginx to host a custom website</li>
    <li>Implemented Elastic IP addressing for consistent public access</li>
    <li>Automated server provisioning using Cloud-Init user data scripts</li>
    <li>Investigated and resolved AMI replacement, networking, and provisioning issues</li>
    <li>Successfully validated Infrastructure as Code through complete destroy-and-rebuild testing using Terraform</li>
</ul>

<p>
This project demonstrates practical experience with AWS, Linux administration, Infrastructure as Code, automation, cloud security, and troubleshooting.
</p>
